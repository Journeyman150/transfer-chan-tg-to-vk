1. Мини-проект для переноса контента из канала Telegram в канал Вконтакте. 

2. Т.к. проект мини, строгих требований к архитектуре нет. Проект должен быть на Go. Кол-во кода должно быть по возможности минимальным. Комментировать очевидные вещи не нужно. Код должен быть безопасным и защищен от паник. Оптимизаций производительности делать не нужно, если это приведет к существенному увеличению и усложнению кода.

3. Задача - перенести уже существующий контент из канала Telegram в канал Вконтакте.

4. Архитектурные планы находятся в папке проекта ./plans

5. Текущая ОС, где пишется код, - это Windows 11 Pro - **НЕ** НУЖНО пытаться вводить cli команды из Linux, вместо этого нужно использовать команды для Windows (и PowerShell).
